# トラブルシューティング

## リリースやダウンロードにアクセスできない

リリースの XPI と `SHA256SUMS` はログインせずにダウンロードできます。ソースアーカイブではなく XPI を取得してください。インストール失敗時は Zotero のバージョンと `SHA256SUMS` を確認します。

## タスクがない、PDF が見つからない

解析が有効・保存済みで、PDF がローカルにあるか確認します。不足ファイルは自動取得しません。登録済み項目には**添付ファイルを解析**を使います。PDF 以外はメタデータのみ保持できます。

## 待機が続く、処理が失敗する

抽出段階と詳細を確認します。サービス側の待機はローカル処理と異なり、進捗不明は完了を意味しません。サービス、接続先、認証、利用枠、通信、制限を確認し、同じ文献を追加し直すより失敗段階を再試行します。

受理済みタスクは元のサービス情報を保持します。切替後も再開には元の接続先とキーが必要です。解析の無効化は実行済みの要求を取り消しません。

## 本文はあるが意味検索が使えない

モデルが有効・保存・適用済みで、埋め込みの接続テストが成功するか確認します。インポートタスクの意味検索段階と起動時復旧案内を確認し、モデルと次元数をベクトル空間に合わせてください。

**既存の文献をベクトル化**は不足する埋め込みを生成し、利用枠を消費する場合があります。保存済みベクトルからの再構築は**検索索引を修復**を使い、新しい埋め込みは生成しません。

## Markdown が空または古い

公開完了後、処理対象 PDF を開き直して **M** を押します。既存内容には新しい解析規則が自動適用されず、明示的な再処理が必要です。閉じる前や再処理前に未保存内容を控えてください。

## 設定が保存できない

検証メッセージを確認します。別ウィンドウや外部編集で設定が変更された場合は、入力を控えて再読込みし、やり直してください。接続テスト成功は保存を意味しません。

## MCP 接続失敗

- 稼働状態と実際のアドレスを確認します。
- Zotero を実行し、PC のスリープを避けます。
- クライアントを同じ PC で動かし、認証付き Streamable HTTP に対応しているか確認します。
- Bearer トークン、期限、対象ライブラリ、権限を確認します。
- ポート競合時は空きローカルポートを適用し、クライアントも変更します。

## 開発自動化中に PDF スクロールが遅い

Windows UI Automation クライアントは Zotero のアクセシビリティを有効にし、スクロールを妨げる場合があります。隔離検証で Codex computer-use ヘルパーとの干渉が確認されています。該当タスクのセッションとヘルパーを終了し、隔離 Zotero を再起動して比較してください。すべての環境に同じ問題がある証拠ではありません。

解決しない場合は[サポート](support.md)の手順で、最小再現と機密情報を除いた情報を提出してください。
