# サービスの設定

**Zotero 設定 → Knowledge MCP** を開きます。**文書解析**、**モデルと検索**、**MCP 接続**にはそれぞれ保存・適用操作があります。タブを切り替えても未保存の入力は保持されます。

## 文書解析

| サービス | 接続先 | モデル |
| --- | --- | --- |
| PaddleOCR | `https://paddleocr.aistudio-app.com/api/v2/ocr/jobs` | `PaddleOCR-VL-1.6` |
| MinerU | `https://mineru.net/api/v4` | `vlm` |

サービスを選び、API キーまたはトークンを入力して有効化・保存します。切替時も各サービスの認証情報とオプションを保持します。モデルは選択した解析サービスで固定され、任意の OCR API がそのまま使えるわけではありません。

外部接続は HTTPS が必要で、HTTP はループバックサービスのみです。URL にパスワード、クエリ、フラグメントは含められません。受理済みタスクは開始時のサービスと接続先を保持し、現在の選択を変えても転送されません。

キュー設定ではローカル実行枠、追跡する遠隔ジョブ、ポーリング、タイムアウト、ファイル・結果の上限を調整します。まず初期値を使用してください。時間は秒、容量は MB 表示です（1 MB = 1,048,576 バイト）。

## モデルと検索

同梱プロバイダーは **Bailian** です。初期モデルは `qwen3.7-text-embedding` と `qwen3.7-text-rerank`、ベクトル次元は 768 です。アカウントがモデル、リージョン、接続先、次元数に対応するか確認してください。

1. 対応する埋め込み接続先、モデル、キーを入力します。
2. 必要なら再ランキングを設定します。候補本文がサービスに送られる場合があり、専用キーか埋め込みキーの共用を選べます。
3. 各接続をテストします。現在の入力で実行しますが保存はしません。
4. サービスを有効化し、**保存して適用**した後、適用状態を確認します。
5. 必要に応じて**既存の文献をベクトル化**し、不足する埋め込みを生成します。

保存済みキーの入力欄を空にすると元のキーを保持します。接続成功、設定保存、実行時適用は別の状態です。

埋め込みモデル、接続先、次元数を変えるとベクトル空間が変わります。確認時に旧ベクトルの保持・削除・変更取消を選択してください。互換性のない空間は混ぜません。

**検索索引を修復**は保存済みベクトルからローカル再構築し、新しい埋め込みを要求しません。**既存の文献をベクトル化**は外部サービスを呼び出し、利用枠を消費する場合があります。[トラブルシューティング](troubleshooting.md)を参照してください。

## MCP 接続

ローカル MCP は任意で、初期状態は無効です。ローカル AI クライアントが必要な場合に有効化し、ポートを適用して、ライブラリと権限を明示したトークンを作ります。[MCP ガイド](mcp.md)を参照してください。
