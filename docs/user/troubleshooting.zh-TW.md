# 疑難排解

## 無法存取版本或下載

釋出頁的 XPI 和 `SHA256SUMS` 可直接下載，無需登入。請下載 XPI，而非原始碼壓縮包。安裝失敗時核對 Zotero 版本，並比較 `SHA256SUMS`。

## 沒有解析任務或缺少 PDF

確認解析已啟用並儲存，附件確為 PDF 且已在 Zotero 本機可用，外掛不會下載缺失檔案。對已入庫條目使用**解析附件**；非 PDF 條目可以只保留後設資料。

## 任務一直排隊或失敗

檢視擷取階段和處理詳情。服務供應商排隊與本機處理不同，進度未知不代表已完成。核對提供方、介面、憑據、額度、網路和檔案限制。重試失敗階段，無需反覆新增同一文獻。

已接受任務保留原提供方身分。切換解析器後若需恢復該任務，應保留匹配的原介面和金鑰設定。關閉解析不會取消已經執行的請求。

## 有正文但無語意結果

確認模型服務已啟用、儲存並套用，嵌入連線測試成功。檢查匯入任務的語意階段及啟動恢復提示，模型和維度必須與內容向量空間匹配。

**向量化現有文獻**會補充缺失嵌入，可能消耗額度；已有向量但本機索引需重建時，使用**修復檢索索引**，不會重新生成嵌入。

## Markdown 面板為空或過時

等待內容釋出成功，關閉並重開對應 PDF，點選 **M**。確認開啟的是實際處理的附件。已有內容不會自動採用新解析規範，需要明確重新處理；關閉或重新處理前保留未儲存修改。

## 無法儲存設定

檢視驗證提示。其他視窗或外部編輯器可能已修改設定。保留未儲存值，重新載入表單再試。連線測試成功不會儲存設定。

## MCP 無法連線

- 檢視執行狀態並複製實際設定地址。
- 保持 Zotero 執行且電腦喚醒。
- 確認用戶端與 Zotero 同機，且支援認證 Streamable HTTP。
- 核對 Bearer 權杖、有效期、授權知識庫和權限。
- 連接埠占用時改用空閒本機連接埠，套用後同步更新用戶端。

## 開發自動化期間 PDF 滾動卡頓

Windows UI Automation 用戶端可能啟用 Zotero 無障礙服務並干擾 PDF 滾動；隔離開發檢查中曾觀察到 Codex computer-use 輔助程序造成此問題。關閉該任務的自動化會話及輔助程序，重新啟動隔離 Zotero 後再比較。不要據此認定所有安裝都有同一問題。

仍有問題時，請按[支援指南](support.md)提供最小重現及去識別化資訊。
