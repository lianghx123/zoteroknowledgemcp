# 支援與相容性

## 預覽版狀態

目前原始碼版本為 **0.2.0-preview.1**，尚無已釋出安裝包，面向 Zotero **10.0.x**。原生開發驗證使用 Windows 和 Zotero 10.0.6–10.0.8；macOS、Linux、長期可靠性及完整人工介面和語言驗收仍未完成。Node 自動測試模擬原生行為，不能替代 Zotero 執行時或服務供應商驗證。

外掛介面與本手冊均支援英語、簡體中文、繁體中文、德語、法語、西班牙語和日語。使用語言選擇器切換目前頁面。

變更和限制見[發行說明](https://github.com/lianghx123/zoteroknowledgemcp/releases)，開發驗收詳情見[交付狀態](https://github.com/lianghx123/zoteroknowledgemcp/blob/main/docs/development/project-status.md)。十萬向量基準不代表完整工作流程的文獻容量或獨立評估的檢索品質。

## 報告問題

請使用[問題追蹤器](https://github.com/lianghx123/zoteroknowledgemcp/issues)。儲存庫為私有時僅有權限的帳號可存取。請包含：

- 外掛版本、Zotero 版本和作業系統。
- 重現步驟、預期行為和實際行為。
- 相關任務階段或去識別化錯誤資訊。
- 如有關聯，說明 PDF 是否在本機，以及所選提供方和模型。

不要附帶金鑰、權杖、完整資料目錄或私秘密值獻，儘可能使用可公開分享的材料重現。
