# 支持与兼容性

## 预览版状态

当前发布预览为 **0.2.0-preview.1**，面向 Zotero **10.0.x**。原生开发验证使用 Windows 和 Zotero 10.0.6–10.0.8；macOS、Linux、长期可靠性及完整人工界面和语言验收仍未完成。Node 自动测试模拟原生行为，不能替代 Zotero 运行时或服务商验证。

插件界面与本手册均支持英语、简体中文、繁体中文、德语、法语、西班牙语和日语。使用语言选择器切换当前页面。

变更和限制见[发行说明](https://github.com/lianghx123/zoteroknowledgemcp/releases)，开发验收详情见[交付状态](https://github.com/lianghx123/zoteroknowledgemcp/blob/main/docs/development/project-status.md)。十万向量基准不代表完整工作流的文献容量或独立评估的检索质量。

## 报告问题

请使用[问题跟踪器](https://github.com/lianghx123/zoteroknowledgemcp/issues)。仓库为私有时仅有权限的账号可访问。请包含：

- 插件版本、Zotero 版本和操作系统。
- 复现步骤、预期行为和实际行为。
- 相关任务阶段或脱敏错误信息。
- 如有关联，说明 PDF 是否在本地，以及所选提供方和模型。

不要附带密钥、令牌、完整数据目录或私密钥献，尽可能使用可公开分享的材料复现。
