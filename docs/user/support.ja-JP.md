# サポートと互換性

## プレビュー版の状態

公開済み **0.2.0-preview.1** は Zotero **10.0.x** 向けです。ネイティブ検証は Windows と Zotero 10.0.6–10.0.8 で行いました。macOS、Linux、長期信頼性、全画面・全言語の手動受け入れ検証は未完了です。Node 自動テストはネイティブ動作の模擬であり、Zotero やサービスの実検証を代替しません。

画面と本ガイドは英語、簡体字中国語、繁体字中国語、ドイツ語、フランス語、スペイン語、日本語に対応しています。言語選択で現在のページを切り替えられます。

[リリースノート](https://github.com/lianghx123/zoteroknowledgemcp/releases)と[開発状況](https://github.com/lianghx123/zoteroknowledgemcp/blob/main/docs/development/project-status.md)も参照してください。10 万ベクトルのベンチマークは、全工程の文献容量や独立評価された検索品質を証明しません。

## 問題の報告

[Issue トラッカー](https://github.com/lianghx123/zoteroknowledgemcp/issues)を使います。非公開中は権限が必要です。次を記載してください。

- プラグインと Zotero の版、OS。
- 再現手順、期待する動作と実際の動作。
- 該当段階や機密情報を除いたエラー。
- 関連する場合は PDF のローカル有無とサービス・モデル。

キー、トークン、データ全体、非公開文献は添付しないでください。可能なら共有可能な資料で再現してください。
