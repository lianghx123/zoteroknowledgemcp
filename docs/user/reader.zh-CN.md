# 阅读与编辑提取正文

解析完成后，在 Zotero 原生阅读器中打开 PDF，点击 **M**。Markdown 伴读显示当前附件的已发布正文，以及可用的公式、表格、图片和来源上下文。PDF 与批注仍由原生阅读器管理。

## 导航

- 使用**目录**浏览标题，当前标题及其祖先会随阅读位置更新。
- 使用文内搜索查找当前 PDF 中的文本或模型检索结果。
- 悬停或聚焦已识别引文，查看参考文献和可用的来源导航；歧义匹配可能给出多个候选。
- 使用悬浮阅读栏调整字号或返回顶部。

显示状态、分栏比例、目录设置和字号会跨文献及重启保存。提取和引文匹配可能有误，精确措辞和归属请核对 PDF。

## 修正内容块

1. 点击铅笔图标，或通过文本块右键菜单进入编辑。
2. 编辑 Markdown，在源码与预览间切换；映射支持时可编辑公式源码。
3. 应用块修改，更新当前工作预览、目录和本地文本检索。
4. 按需撤销或重做，然后选择**保存文档**发布修改。

对于来源映射明确的内容块，可修改块类型、插入或确认删除。并非每个内容块都支持全部操作。

应用块修改不等于保存文档。关闭 PDF 阅读器，或重启插件、Zotero，会丢失未保存修改和内存中的撤销历史；仅隐藏 Markdown 面板会保留工作状态。

保存会进行冲突检测并发布新内容版本。未变化且匹配的向量可复用，改变的文本遵循后台嵌入策略。若保存报告冲突，重新载入前请保留未保存文本。
