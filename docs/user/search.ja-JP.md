# 文献と文章の検索

対象範囲を選び、Zotero の検索メニューから**ナレッジベース**のモードを選択します。空でないクエリを入力し **Enter** で実行します。モード変更だけでは一覧を保ち、空欄で Enter を押すとモデル呼出しなしでフィルターを解除します。

| モード | 対象 | 必要なもの |
| --- | --- | --- |
| テキスト | ローカル本文とメタデータ | 文章の一致には公開済み本文 |
| セマンティック | 意味に基づくベクトル検索 | 有効な埋め込みサービスと対応する索引 |
| 拡張セマンティック | セマンティック検索後に再ランキング | 埋め込み・再ランキング設定と対応索引 |
| 融合 | テキストと意味検索を統合 | 利用可能な経路。意味検索の準備状態が結果に影響 |

結果の標準展開矢印から一致本文、メタデータ、ソースリンクを確認できます。低スコアの結果には簡潔な関連性案内が付きますが、引き続き閲覧可能です。スコアは順位の指標であり、事実の保証や原文確認の代用ではありません。

**マイナレッジベース**は有効なライブラリ全体を検索します。特定ライブラリやフォルダーで範囲を狭められます。ごみ箱には独自の復元用検索範囲があります。

## 開いている PDF 内を検索

Markdown パネルには文書内検索があり、現在の添付内容をテキスト・セマンティック・拡張セマンティック・融合モードで検索します。結果を選ぶと元のブロックへ移動し、閉じると目次に戻ります。

セマンティック索引の準備前でもテキスト検索は使えます。意味検索の結果がない場合はインポートタスク、モデル設定、復旧状態を確認します。PDF 再処理前に[トラブルシューティング](troubleshooting.md)を確認してください。
