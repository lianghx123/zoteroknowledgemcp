# 配置服务

打开 **Zotero 设置 → Knowledge MCP**。设置分为**文档解析**、**模型与检索**和 **MCP 连接**三个标签页，各自有保存或应用操作。切换标签页会保留尚未保存的输入。

## 文档解析

| 解析器 | 接口 | 模型 |
| --- | --- | --- |
| PaddleOCR | `https://paddleocr.aistudio-app.com/api/v2/ocr/jobs` | `PaddleOCR-VL-1.6` |
| MinerU | `https://mineru.net/api/v4` | `vlm` |

选择解析器，填写对应 API 密钥或令牌，启用并保存。切换时各解析器保留自己的凭据与选项。模型由解析器固定，任意 OCR 接口不会自动兼容。

外部接口必须使用 HTTPS；普通 HTTP 仅限本机回环服务。URL 不得包含密码、查询参数或片段。已接受的任务保留开始时的接口与解析器身份，切换当前解析器不会重定向该任务。

队列设置控制本地执行槽位、跟踪的远程任务、轮询、超时及文件和结果大小。建议先用默认值。时间显示为秒，大小显示为 MB（1 MB = 1,048,576 字节）。

## 模型与检索

当前提供 **Bailian（百炼）**，默认模型为 `qwen3.7-text-embedding` 和 `qwen3.7-text-rerank`，默认向量维度为 768。请确认账号支持所选模型、地域、接口和维度。

1. 填写与提供方兼容的嵌入接口、模型和密钥。
2. 按需配置重排。重排可能把检索片段发给提供方；可独立配置凭据或共用嵌入密钥。
3. 分别测试服务连接。测试使用当前表单内容，不会保存设置。
4. 启用服务，选择**保存并应用**，确认已应用状态。
5. 按需使用**向量化已有文献**，为已处理内容补充缺失的嵌入。

已保存密钥的输入框留空会保留原密钥。连接成功、配置已保存和运行时已应用是不同状态。

修改嵌入模型、接口或维度会改变向量空间。提示时可保留旧空间向量、清除旧向量或取消修改；不兼容空间的向量不会混用。

**修复检索索引**仅用已保存向量重建本地索引，不生成新嵌入；**向量化已有文献**可能请求服务并消耗额度。参见[故障排查](troubleshooting.md)。

## MCP 连接

本地 MCP 可选，默认关闭。仅在本机 AI 客户端需要访问时启用。配置端口、应用连接设置，再创建明确指定知识库和权限的令牌，详见 [MCP 指南](mcp.md)。
