# データとプライバシー

現在のプレビュー版のデータ動作を説明します。利用するプロバイダーや AI クライアントには、それぞれの規約、保存方針、料金があります。

## ローカルに保存するもの

ナレッジ DB、処理状態、抽出内容、成果物、ベクトル索引は Zotero データディレクトリ内の `knowledgemcp/` に保存します。SQLite スキーマは Zotero 標準 DB と別で、元の添付は Zotero が管理します。

解析設定は現在、再利用できる API キーを `parsing.json` に平文保存します。ディレクトリとバックアップを保護してください。埋め込み・再ランキングのキーは Gecko Login Manager を使い、設定は参照だけを保持します。MCP トークンはハッシュを保存し、復元可能なシークレットは保存しません。

## 外部に送信する場合

| 操作 | 設定先へ送るデータ |
| --- | --- |
| PDF 解析 | 選択した PDF ファイル |
| 本文の埋め込み | 選択された抽出テキストの断片 |
| セマンティック検索 | 埋め込み対象の検索語 |
| 任意の再ランキング | 検索語と候補本文 |
| 認可済み MCP | 要求された内容をクライアントに返す |

ローカルのテキスト検索と索引修復には埋め込み要求は不要です。プラグイン独自のクラウド同期や遠隔アカウントサービスはありません。外部クライアントは追加のモデル・通信処理を行う場合があります。

## バックアップと削除

`knowledgemcp/` を含むデータ全体を外部にバックアップする前に Zotero を終了してください。DB 更新用スナップショットは全成果物や索引を含まず、完全なバックアップではありません。

無効化やアンインストールはデータを保持します。Zotero のディレクトリ初期化やアカウント変更は、プラグイン保存領域とスナップショットも削除する場合があります。バックアップは外部に保管してください。完全復元やスキーマのダウングレード機能は未提供です。

## 情報を共有する前に

ログ内の PDF 本文、タイトル、ローカルパス、URL、認証情報を確認してください。公開 Issue に Zotero ディレクトリ、DB、トークン、キーを添付しないでください。[サポート](support.md)を参照してください。
