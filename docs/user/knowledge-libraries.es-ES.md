# Bibliotecas de conocimiento

Las bibliotecas de conocimiento y sus carpetas organizan los documentos seleccionados, aparte de las bibliotecas personales/de grupo y colecciones nativas de Zotero. Un documento puede pertenecer a varias ubicaciones y compartir su contenido procesado.

## Añadir documentos

Usa **Añadir a la base de conocimientos** en el menú contextual de un elemento o colección nativa y selecciona el destino. Un adjunto hijo incorpora su documento padre y enlaza sus adjuntos. Las notas y anotaciones independientes no se incorporan como documentos bibliográficos.

El alta puntual de una colección incluye sus elementos directos. Los vínculos continuos sincronizan descendientes por separado. Los PDF aptos se procesan si el análisis está activado. Descarga o restaura primero los PDF ausentes en Zotero; el complemento no lo hace automáticamente.

## Sincronizar una colección

Crea un vínculo explícito entre una colección nativa y una ubicación mediante la acción de sincronización. Puede reflejar descendientes; un alta puntual no implica un vínculo continuo. Consulta su estado en las vistas de sincronización/tareas.

La sincronización es unidireccional: los cambios nativos actualizan la copia. Reorganizar carpetas de conocimiento no cambia nombres ni ubicaciones de colecciones Zotero.

## Retirar y recuperar

Retirar de una carpeta elimina esa ubicación; retirar de una biblioteca afecta a esa pertenencia. Otras pertenencias pueden mantenerse. No se borran el elemento original ni su PDF en Zotero.

La papelera de conocimiento permite revisar y restaurar retiradas recuperables. Comprueba el destino antes del borrado permanente. La papelera no sustituye una copia externa.

La papelera nativa o fuentes no disponibles pueden ocultar documentos de resultados activos. Restaurar el original y actualizar metadatos puede recuperar su disponibilidad. Consulta [Datos y privacidad](privacy.md).
