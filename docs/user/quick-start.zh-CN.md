# 处理第一篇文献

先选择一篇已在 Zotero 本地保存 PDF 的文献。处理时会将 PDF 上传至配置的解析服务；使用机密材料前，请查看服务商条款。

## 1. 配置解析器

打开 **Zotero 设置 → Knowledge MCP → 文档解析**。选择 **PaddleOCR (PaddleOCR VL-1.6)** 或 **MinerU (VLM)**，填写对应凭据，启用解析并保存。接口详情见[配置服务](configuration.md)。

## 2. 添加文献

在 Zotero 原生文献视图中右键点击条目，选择**添加到知识库**及目标知识库或文件夹。插件保存元数据，并为符合条件的 PDF 附件排队。同一文献重复添加到同一位置不会产生重复资源。

没有 PDF 的条目也能保存元数据，但无法仅凭元数据生成提取正文。

## 3. 查看处理进度

打开**导入任务**，工作流分为三个阶段：

1. 添加到知识库。
2. 提取文献内容。
3. 准备语义检索（启用时）。

提取包括准备、上传、服务端等待、解析、下载和本地保存。服务商的页数百分比仅表示解析进度，并非整个工作流的完成比例。可以查看错误并使用取消、重试操作；重试向量阶段不会重新上传 PDF。

## 4. 阅读结果

在 Zotero 原生阅读器中打开 PDF，点击 **M** 显示 Markdown 伴读。如果处理完成前已打开阅读器，请关闭后重新打开。通过目录、文内搜索和引文预览导航，详见[阅读与编辑](reader.md)。

## 5. 检索或连接客户端

已发布正文可直接进行文本检索，无需嵌入服务。语义检索需要配置并启用模型服务，等待索引完成。随后可[检索](search.md)或[连接本机 AI 客户端](mcp.md)。
