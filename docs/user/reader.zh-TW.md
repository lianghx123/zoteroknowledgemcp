# 閱讀與編輯擷取正文

解析完成後，在 Zotero 原生閱讀器中開啟 PDF，點選 **M**。Markdown 伴讀顯示目前附件的已釋出正文，以及可用的公式、表格、圖片和來源上下文。PDF 與批註仍由原生閱讀器管理。

## 導覽

- 使用**目錄**瀏覽標題，目前標題及其祖先會隨閱讀位置更新。
- 使用文內搜尋查詢目前 PDF 中的文字或模型檢索結果。
- 懸停或聚焦已識別引文，檢視參考文獻和可用的來源導覽；歧義匹配可能給出多個候選。
- 使用懸浮閱讀欄調整字級或返回頂部。

顯示狀態、分欄比例、目錄設定和字級會跨文獻及重新啟動儲存。擷取和引文匹配可能有誤，精確措辭和歸屬請核對 PDF。

## 修正內容區塊

1. 點選鉛筆圖示，或透過文字區塊右鍵選單進入編輯。
2. 編輯 Markdown，在原始碼與預覽間切換；對應支援時可編輯公式原始碼。
3. 套用區區塊修改，更新目前工作預覽、目錄和本機文字檢索。
4. 按需撤銷或重做，然後選擇**儲存文件**釋出修改。

對於來源對應明確的內容區塊，可修改塊類型、插入或確認刪除。並非每個內容區塊都支援全部操作。

套用區區塊修改不等於儲存文件。關閉 PDF 閱讀器，或重新啟動外掛、Zotero，會遺失未儲存修改和記憶體中的撤銷歷史；僅隱藏 Markdown 面板會保留工作狀態。

儲存會進行衝突檢測並發布新內容版本。未變化且匹配的向量可重複使用，改變的文字遵循背景嵌入策略。若儲存報告衝突，重新載入前請保留未儲存文字。
