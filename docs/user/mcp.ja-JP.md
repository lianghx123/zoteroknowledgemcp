# AI クライアントの接続

MCP では認可済みクライアントが文献発見、文章検索、構造化内容の読取り、明示的に許可された注釈・要約の書込みを行えます。認証付き Streamable HTTP（応答は SSE のみ）で 16 ツールを提供します。旧式の分離した HTTP+SSE エンドポイントはありません。

## アクセスを有効化

1. **Zotero 設定 → Knowledge MCP → MCP 接続**を開きます。
2. ローカル MCP を有効化して適用します。初期アドレスは `http://127.0.0.1:23126/mcp/knowledge` ですが、実際の設定に従ってください。
3. 名前付きトークンを作り、対象ライブラリと必要権限を明示します。検索・読取りと、注釈・要約の書込みは別の権限です。
4. シークレットをすぐにコピーします。一度しか表示されず、復元できません。
5. クライアントのリモート・HTTP MCP 設定にアドレスと Bearer トークンを登録します。Zotero を起動し、PC をスリープさせないでください。

有効期限は 30、90、180、365 日から選べます。名前、ライブラリ、権限の変更はシークレットと期限を保持します。不要時は失効させてください。既存接続でも、その後のリクエストに失効が適用されます。

## Codex の例

クライアント起動環境に `ZOTERO_KNOWLEDGE_MCP_TOKEN` を設定し、実行します。

```sh
codex mcp add zotero-knowledge --url http://127.0.0.1:23126/mcp/knowledge --bearer-token-env-var ZOTERO_KNOWLEDGE_MCP_TOKEN
```

設定画面にはアドレスと対応コマンドのコピー操作もあります。ポート変更時は URL を合わせてください。環境変数はクライアントの手順に従い、トークンをスクリーンショット、リポジトリ、問題報告に含めないでください。

## 接続範囲

Zotero の実行中、同じ PC のループバック接続だけを受け付けます。公開 HTTPS、アカウント式遠隔アクセス、リレー・クラウド接続は未提供です。クラウド側のクライアントは PC のループバックへ直接接続できません。許可したクライアントは対象データを取得し、自身のモデルサービスに送る場合があります。

ツール構造と互換性は [MCP 開発者リファレンス](https://github.com/lianghx123/zoteroknowledgemcp/blob/main/docs/development/mcp.md)を参照してください。
