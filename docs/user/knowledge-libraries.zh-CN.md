# 知识库

知识库及其文件夹组织插件中选定的文献，独立于 Zotero 个人库、群组库和原生分类。同一文献可属于多个知识位置，并共享已处理内容。

## 添加文献

在 Zotero 原生条目或分类的右键菜单中选择**添加到知识库**及目标位置。选择子附件会添加其父文献并关联附件；独立笔记和批注不会作为独立文献加入。

一次性添加分类只包括其直接条目；持续分类绑定另有后代同步工作流。启用解析后，符合条件的 PDF 可进入处理。缺失的 PDF 需先在 Zotero 下载或恢复，插件不会自动下载。

## 同步分类

通过分类同步操作，将原生分类与知识位置明确绑定。绑定可镜像后代；一次性添加并不建立持续绑定。在同步或任务视图中查看状态与进度。

同步为单向：原生元数据修改刷新知识副本，整理知识文件夹不会重命名或移动 Zotero 原生分类。

## 移除与恢复

从文件夹移除文献只移除该放置关系；从知识库移除则影响该库中的成员关系，其他库的成员关系可保留。这些操作不会删除原始 Zotero 条目或 PDF。

在知识库回收站查看和恢复可恢复的插件移除项。永久删除前请核对目标；回收站不是外部备份。

Zotero 原生回收站或不可用来源可能使文献不再出现在活动知识结果中。恢复原条目并刷新元数据可恢复可用性。重置和备份行为见[数据与隐私](privacy.md)。
