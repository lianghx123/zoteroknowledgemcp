# 設定服務

開啟 **Zotero 設定 → Knowledge MCP**。設定分為**文件解析**、**模型與檢索**和 **MCP 連線**三個標籤頁，各自有儲存或套用操作。切換標籤頁會保留尚未儲存的輸入。

## 文件解析

| 解析器 | 介面 | 模型 |
| --- | --- | --- |
| PaddleOCR | `https://paddleocr.aistudio-app.com/api/v2/ocr/jobs` | `PaddleOCR-VL-1.6` |
| MinerU | `https://mineru.net/api/v4` | `vlm` |

選擇解析器，填寫對應 API 金鑰或權杖，啟用並儲存。切換時各解析器保留自己的憑據與選項。模型由解析器固定，任意 OCR 介面不會自動相容。

外部介面必須使用 HTTPS；普通 HTTP 僅限本機迴環服務。URL 不得包含密碼、查詢參數或片段。已接受的任務保留開始時的介面與解析器身分，切換目前解析器不會重新導向該任務。

佇列設定控制本機執行槽位、追蹤的遠端任務、輪詢、逾時及檔案和結果大小。建議先用預設值。時間顯示為秒，大小顯示為 MB（1 MB = 1,048,576 位元組）。

## 模型與檢索

目前提供 **Bailian（百煉）**，預設模型為 `qwen3.7-text-embedding` 和 `qwen3.7-text-rerank`，預設向量維度為 768。請確認帳號支援所選模型、地域、介面和維度。

1. 填寫與提供方相容的嵌入介面、模型和金鑰。
2. 按需設定重排。重排可能把檢索片段發給提供方；可獨立設定憑據或共用嵌入金鑰。
3. 分別測試服務連線。測試使用目前表單內容，不會儲存設定。
4. 啟用服務，選擇**儲存並套用**，確認已套用狀態。
5. 按需使用**向量化現有文獻**，為已處理內容補充缺失的嵌入。

已儲存金鑰的輸入框留空會保留原金鑰。連線成功、設定已儲存和執行時已套用是不同狀態。

修改嵌入模型、介面或維度會改變向量空間。提示時可保留舊空間向量、清除舊向量或取消修改；不相容空間的向量不會混用。

**修復檢索索引**僅用已儲存向量重建本機索引，不生成新嵌入；**向量化現有文獻**可能請求服務並消耗額度。參見[疑難排解](troubleshooting.md)。

## MCP 連線

本機 MCP 可選，預設關閉。僅在本機 AI 用戶端需要存取時啟用。設定連接埠、套用連線設定，再建立明確指定知識庫和權限的權杖，詳見 [MCP 指南](mcp.md)。
