# 抽出テキストの閲覧と編集

解析後、標準リーダーで PDF を開き **M** をクリックします。Markdown パネルは現在の添付の公開済み本文と、利用できる数式、表、画像、ソース情報を表示します。PDF と注釈は標準リーダーで管理されます。

## 移動

- **目次**で見出しを移動できます。現在の見出しと祖先は読書位置に追従します。
- 文書内検索で本文やモデルによる結果を探します。
- 認識した引用にマウスを重ねるかフォーカスすると参考文献と操作が表示されます。曖昧な場合は候補が複数あります。
- 浮動ツールバーで文字サイズを変更し、先頭に戻れます。

表示状態、分割比率、目次設定、文字サイズは文書や再起動をまたいで保持されます。抽出や引用照合は完全ではないため、正確な文言や出典は PDF で確認してください。

## ブロックを修正

1. 鉛筆アイコンまたはテキストブロックの右クリックから編集します。
2. Markdown を編集し、ソースとプレビューを切り替えます。対応するマッピングがあれば数式ソースも編集できます。
3. ブロック変更を適用して、作業中のプレビュー、目次、ローカル検索を更新します。
4. 元に戻す・やり直しを使い、**文書を保存**して変更を公開します。

ソース対応が明確なブロックでは種類変更、挿入、確認付き削除を行えます。すべてのブロックですべての操作が可能とは限りません。

ブロックの適用は文書保存とは異なります。PDF リーダーを閉じるか、プラグインや Zotero を再起動すると未保存変更とメモリ内履歴は失われます。Markdown を隠すだけなら作業状態を保持します。

保存時は競合を検出し、新しいコンテンツ世代を公開します。未変更で互換性のあるベクトルは再利用でき、変更本文はバックグラウンド埋め込み設定に従います。競合時は再読込みの前に未保存テキストを控えてください。
