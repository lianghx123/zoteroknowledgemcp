# Leer y editar el texto extraído

Tras el análisis, abre el PDF en el lector nativo de Zotero y pulsa **M**. El panel Markdown muestra el texto publicado del adjunto con fórmulas, tablas, imágenes y contexto disponibles. El PDF y las anotaciones permanecen en el lector nativo.

## Navegación

- El **Índice** sigue el encabezado actual y sus antecesores durante la lectura.
- La búsqueda documental encuentra texto o resultados de modelos dentro del PDF.
- Pasa el cursor o enfoca una cita reconocida para consultar referencias y acciones. Las coincidencias ambiguas pueden mostrar varios candidatos.
- La barra flotante cambia el tamaño del texto o vuelve al inicio.

Visibilidad, proporción de paneles, ajustes del índice y tamaño persisten entre documentos y reinicios. La extracción y las citas pueden contener errores; comprueba redacción y atribuciones exactas en el PDF.

## Corregir un bloque

1. Activa la edición con el lápiz o el menú contextual del bloque.
2. Edita Markdown y alterna código y vista previa. Las fórmulas son editables cuando el mapeo lo permite.
3. Aplica el bloque para actualizar la vista de trabajo, el índice y la búsqueda textual local.
4. Usa deshacer/rehacer y **Guardar documento** para publicar los cambios.

El cambio de tipo, la inserción y el borrado confirmado están disponibles para bloques con origen inequívoco. No todos admiten todas las operaciones.

Aplicar un bloque no guarda el documento. Los cambios sin guardar y el historial en memoria se pierden al cerrar el lector PDF o reiniciar Zotero/el complemento. Ocultar Markdown conserva la sesión.

Guardar publica una generación nueva con detección de conflictos. Se pueden reutilizar vectores compatibles sin cambios; el texto modificado sigue la política de embeddings en segundo plano. Ante un conflicto, conserva el texto pendiente antes de recargar.
