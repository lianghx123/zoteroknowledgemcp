# ナレッジライブラリ

ナレッジライブラリとフォルダーは、選択した文献を Zotero の個人・グループライブラリや標準コレクションとは別に整理します。同じ文献を複数の場所に登録し、処理済み内容を共有できます。

## 文献の追加

標準項目やコレクションの右クリックから**ナレッジベースに追加**を選びます。子添付ファイルを選ぶと親文献が登録され、その添付が関連付けられます。独立したノートや注釈は独立文献として登録されません。

一度限りのコレクション追加は直下の項目が対象です。継続的なリンクは子孫を別の同期処理で扱います。解析有効時に対象 PDF を処理します。見つからない PDF は先に Zotero で取得・復元してください。自動ダウンロードは行いません。

## コレクションの同期

同期操作で標準コレクションと保存先を明示的に関連付けます。子孫を反映できますが、一度限りの追加は継続リンクを意味しません。同期・タスク画面で状態を確認できます。

同期は一方向で、標準メタデータの変更がコピーに反映されます。ナレッジ側の整理で Zotero コレクションの名前や配置は変わりません。

## 削除と復元

フォルダーからの削除は配置のみ、ライブラリからの削除はその所属を対象とします。他の所属は残せます。元の Zotero 項目と PDF は削除されません。

ナレッジのごみ箱で復元可能な削除を確認・復元できます。完全削除前に対象を確認してください。ごみ箱は外部バックアップの代わりにはなりません。

標準ごみ箱や利用不能なソースにより、文献が有効な検索結果から隠れる場合があります。元の項目を復元してメタデータを更新すると可用性を回復できる場合があります。[データとプライバシー](privacy.md)を参照してください。
