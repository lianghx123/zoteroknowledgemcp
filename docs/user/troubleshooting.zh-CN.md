# 故障排查

## 无法访问版本或下载

发布页的 XPI 和 `SHA256SUMS` 可直接下载，无需登录。请下载 XPI，而非源码压缩包。安装失败时核对 Zotero 版本，并比较 `SHA256SUMS`。

## 没有解析任务或缺少 PDF

确认解析已启用并保存，附件确为 PDF 且已在 Zotero 本地可用，插件不会下载缺失文件。对已入库条目使用**解析附件**；非 PDF 条目可以只保留元数据。

## 任务一直排队或失败

查看提取阶段和处理详情。服务商排队与本地处理不同，进度未知不代表已完成。核对提供方、接口、凭据、额度、网络和文件限制。重试失败阶段，无需反复添加同一文献。

已接受任务保留原提供方身份。切换解析器后若需恢复该任务，应保留匹配的原接口和密钥配置。关闭解析不会取消已经运行的请求。

## 有正文但无语义结果

确认模型服务已启用、保存并应用，嵌入连接测试成功。检查导入任务的语义阶段及启动恢复提示，模型和维度必须与内容向量空间匹配。

**向量化已有文献**会补充缺失嵌入，可能消耗额度；已有向量但本地索引需重建时，使用**修复检索索引**，不会重新生成嵌入。

## Markdown 面板为空或过时

等待内容发布成功，关闭并重开对应 PDF，点击 **M**。确认打开的是实际处理的附件。已有内容不会自动采用新解析规范，需要明确重新处理；关闭或重新处理前保留未保存修改。

## 无法保存设置

查看验证提示。其他窗口或外部编辑器可能已修改配置。保留未保存值，重新载入表单再试。连接测试成功不会保存配置。

## MCP 无法连接

- 查看运行状态并复制实际配置地址。
- 保持 Zotero 运行且电脑唤醒。
- 确认客户端与 Zotero 同机，且支持认证 Streamable HTTP。
- 核对 Bearer 令牌、有效期、授权知识库和权限。
- 端口占用时改用空闲本地端口，应用后同步更新客户端。

## 开发自动化期间 PDF 滚动卡顿

Windows UI Automation 客户端可能激活 Zotero 无障碍服务并干扰 PDF 滚动；隔离开发检查中曾观察到 Codex computer-use 辅助进程造成此问题。关闭该任务的自动化会话及辅助进程，重启隔离 Zotero 后再比较。不要据此认定所有安装都有同一问题。

仍有问题时，请按[支持指南](support.md)提供最小复现及脱敏信息。
