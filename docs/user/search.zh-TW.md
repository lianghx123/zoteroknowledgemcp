# 檢索文獻與片段

選擇知識範圍，在 Zotero 搜尋下拉選單中選擇**知識庫**檢索模式。輸入非空查詢後按 **Enter** 提交；僅切換模式會保留目前列表。空查詢按 Enter 會清除外掛結果過濾，不請求模型。

| 模式 | 檢索依據 | 要求 |
| --- | --- | --- |
| 文字 | 本機正文和後設資料 | 片段匹配需要已釋出正文 |
| 語意 | 向量語意檢索 | 啟用嵌入服務，且有匹配的已索引內容 |
| 增強語意 | 語意檢索後重排 | 已設定嵌入與重排服務及匹配索引 |
| 融合 | 合併文字與語意檢索 | 使用可用通道；語意就緒情況影響結果 |

點選結果旁的原生展開箭頭檢視匹配片段、後設資料欄位和來源連結。較低分結果前有簡短相關性提示，仍可檢視這些結果。分數僅用於排序，不代表事實確定性，也不能替代閱讀來源。

**我的知識庫**可跨活動知識庫檢索；選擇具體庫或資料夾可縮小範圍。知識庫資源回收筒使用獨立恢復範圍。

## 在目前 PDF 中檢索

Markdown 伴讀有獨立文內搜尋側欄，支援文字、語意、增強語意和融合模式，只檢索目前附件的目前內容。點選命中項跳轉至來源塊，關閉搜尋後返回目錄。

語意索引就緒前仍可進行文字檢索。語意結果缺失時，檢視匯入任務、模型設定及恢復狀態，重新解析 PDF 前先閱讀[疑難排解](troubleshooting.md)。
