# Support and compatibility

## Preview status

The current published preview is **0.2.0-preview.1**. It targets Zotero **10.0.x**;
native development checks have used Windows with Zotero 10.0.6–10.0.8. macOS,
Linux, long-running reliability and exhaustive manual UI/locale acceptance
remain open. Automated Node tests simulate native behavior and are not a
replacement for Zotero runtime or service-provider verification.

Interfaces include English, Simplified and Traditional Chinese, German, French,
Spanish and Japanese. This user handbook supports the same seven languages;
use the language selector to switch the current page.

See [release notes](https://github.com/lianghx123/zoteroknowledgemcp/releases)
for changes and known limits, and the
[delivery status](https://github.com/lianghx123/zoteroknowledgemcp/blob/main/docs/development/project-status.md)
for development acceptance details. A 100,000-vector benchmark does not establish
full-workflow paper capacity or independently measured retrieval quality.

## Report an issue

The [issue tracker](https://github.com/lianghx123/zoteroknowledgemcp/issues) is public. Sign in to GitHub to open or comment on an issue. Include:

- Plugin version, Zotero version and operating system.
- Steps to reproduce, expected behavior and actual behavior.
- Relevant task stage or sanitized error text.
- Whether the PDF is local and which provider/model is selected, if relevant.

Do not include keys, tokens, a complete data directory or private literature.
Reproduce with a shareable document where possible.
