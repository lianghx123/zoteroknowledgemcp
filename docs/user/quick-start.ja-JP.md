# 最初の文献を処理する

PDF がすでに Zotero のローカルにある文献から始めてください。PDF は設定した解析サービスにアップロードされます。機密資料を扱う前にサービスの利用条件を確認してください。

## 1. 解析サービスを設定

**Zotero 設定 → Knowledge MCP → 文書解析**を開き、**PaddleOCR (PaddleOCR VL-1.6)** または **MinerU (VLM)** を選びます。対応する認証情報を入力し、解析を有効にして保存します。接続先は[サービスの設定](configuration.md)を参照してください。

## 2. 文献を追加

Zotero の標準文献ビューで右クリックし、**ナレッジベースに追加**から対象のライブラリやフォルダーを選びます。メタデータが登録され、対象 PDF がキューに入ります。同じ文献を同じ場所に再追加しても重複リソースは作られません。

PDF のない項目もメタデータを保持できますが、それだけでは抽出本文は生成されません。

## 3. 進捗を確認

**インポートタスク**を開きます。処理は次の段階に分かれます。

1. ナレッジベースに追加。
2. 文献内容を抽出。
3. セマンティック検索を準備（有効時）。

抽出には準備、アップロード、サービス側の待機、解析、ダウンロード、ローカル保存が含まれます。ページ進捗の割合は抽出のみを示し、全工程の割合ではありません。エラーを確認し、取消や再試行を利用できます。ベクトル段階の再試行では PDF を再送信しません。

## 4. 結果を読む

標準 PDF リーダーで文献を開き、**M** をクリックします。処理完了前から開いていた場合は閉じて開き直してください。目次、文書内検索、引用プレビューで移動できます。[閲覧と編集](reader.md)も参照してください。

## 5. 検索またはクライアント接続

公開済み本文は埋め込みサービスなしでテキスト検索できます。セマンティック検索にはモデルサービスを設定・有効化し、索引作成を待ちます。その後、[検索](search.md)または[ローカル AI クライアントの接続](mcp.md)へ進みます。
