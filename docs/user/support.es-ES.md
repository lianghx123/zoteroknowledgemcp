# Asistencia y compatibilidad

## Estado de la versión preliminar

La versión publicada **0.2.0-preview.1** se dirige a Zotero **10.0.x**. Las pruebas nativas usaron Windows y Zotero 10.0.6–10.0.8. Quedan pendientes macOS, Linux, fiabilidad prolongada y validación manual exhaustiva de interfaz/idiomas. Las pruebas Node simulan comportamiento nativo y no sustituyen la validación en Zotero o con proveedores.

La interfaz y el manual admiten inglés, chino simplificado y tradicional, alemán, francés, español y japonés. El selector cambia el idioma de la página actual.

Consulta las [notas de versión](https://github.com/lianghx123/zoteroknowledgemcp/releases) y el [estado de entrega](https://github.com/lianghx123/zoteroknowledgemcp/blob/main/docs/development/project-status.md). Una prueba con 100.000 vectores no demuestra capacidad del flujo completo ni calidad de búsqueda evaluada independientemente.

## Informar de una incidencia

Usa el [gestor de incidencias](https://github.com/lianghx123/zoteroknowledgemcp/issues), accesible solo a cuentas autorizadas mientras el repositorio sea privado. Incluye:

- Versiones del complemento y Zotero, y sistema operativo.
- Pasos, comportamiento esperado y observado.
- Fase relacionada o error depurado.
- Si procede, disponibilidad local del PDF y proveedor/modelo.

No incluyas claves, tokens, directorios completos ni documentos privados. Reproduce con material compartible cuando sea posible.
