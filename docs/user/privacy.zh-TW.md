# 資料與隱私

本頁說明目前預覽版的資料行為。所選服務供應商和 AI 用戶端有各自的條款、保留政策和費用。

## 本機儲存內容

外掛在 Zotero 資料目錄的 `knowledgemcp/` 下儲存知識資料庫、處理狀態、擷取內容、產物和向量索引。SQLite 結構獨立於 Zotero 原生資料庫，原始附件仍由 Zotero 管理。

解析設定目前在本機 `parsing.json` 中明文儲存可重複使用的 API 金鑰，請保護資料目錄和備份。嵌入與重排金鑰使用 Gecko 登入管理器，設定僅儲存憑據引用。MCP 權杖記錄儲存雜湊，不儲存可找回的秘密值。

## 資料何時傳送到外部

| 操作 | 傳送給設定服務的資料 |
| --- | --- |
| PDF 解析 | 選定 PDF 的檔案內容 |
| 內容嵌入 | 選定的擷取文字片段 |
| 語意查詢 | 待嵌入的查詢文字 |
| 可選重排 | 查詢及候選片段 |
| 授權 MCP 存取 | 將請求的知識內容返回用戶端 |

本機文字檢索和索引修復不需要嵌入請求。外掛不提供自己的雲同步或遠端帳號服務；外部用戶端可能有額外的模型和網路行為。

## 備份與移除

外部備份完整資料目錄（含 `knowledgemcp/`）前請關閉 Zotero。資料庫升級快照不包含全部文獻產物和索引，不能代替完整備份。

停用或移除外掛會保留資料。Zotero 資料目錄重設或帳號切換可能刪除目錄，包括外掛儲存及本機快照；請將備份放在目錄之外。外掛暫不提供完整備份恢復或資料庫結構降級工具。

## 分享問題資訊

分享日誌前，檢查 PDF 正文、標題、本機路徑、服務地址和憑據。不要向公開問題附加 Zotero 資料目錄、知識資料庫、權杖或服務金鑰。參見[支援](support.md)。
