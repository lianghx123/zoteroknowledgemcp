# 检索文献与片段

选择知识范围，在 Zotero 搜索下拉菜单中选择**知识库**检索模式。输入非空查询后按 **Enter** 提交；仅切换模式会保留当前列表。空查询按 Enter 会清除插件结果过滤，不请求模型。

| 模式 | 检索依据 | 要求 |
| --- | --- | --- |
| 文本 | 本地正文和元数据 | 片段匹配需要已发布正文 |
| 语义 | 向量语义检索 | 启用嵌入服务，且有匹配的已索引内容 |
| 增强语义 | 语义检索后重排 | 已配置嵌入与重排服务及匹配索引 |
| 融合 | 合并文本与语义检索 | 使用可用通道；语义就绪情况影响结果 |

点击结果旁的原生展开箭头查看匹配片段、元数据字段和来源链接。较低分结果前有简短相关性提示，仍可查看这些结果。分数仅用于排序，不代表事实确定性，也不能替代阅读来源。

**我的知识库**可跨活动知识库检索；选择具体库或文件夹可缩小范围。知识库回收站使用独立恢复范围。

## 在当前 PDF 中检索

Markdown 伴读有独立文内搜索侧栏，支持文本、语义、增强语义和融合模式，只检索当前附件的当前内容。点击命中项跳转至来源块，关闭搜索后返回目录。

语义索引就绪前仍可进行文本检索。语义结果缺失时，查看导入任务、模型设置及恢复状态，重新解析 PDF 前先阅读[故障排查](troubleshooting.md)。
