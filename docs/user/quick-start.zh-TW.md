# 處理第一篇文獻

先選擇一篇已在 Zotero 本機儲存 PDF 的文獻。處理時會將 PDF 上傳至設定的解析服務；使用機密材料前，請檢視服務供應商條款。

## 1. 設定解析器

開啟 **Zotero 設定 → Knowledge MCP → 文件解析**。選擇 **PaddleOCR (PaddleOCR VL-1.6)** 或 **MinerU (VLM)**，填寫對應憑據，啟用解析並儲存。介面詳情見[設定服務](configuration.md)。

## 2. 新增文獻

在 Zotero 原生文獻檢視中右鍵點選條目，選擇**新增至知識庫**及目標知識庫或資料夾。外掛儲存後設資料，並為符合條件的 PDF 附件排隊。同一文獻重複新增到同一位置不會產生重複資源。

沒有 PDF 的條目也能儲存後設資料，但無法僅憑後設資料生成擷取正文。

## 3. 檢視處理進度

開啟**匯入任務**，工作流程分為三個階段：

1. 新增至知識庫。
2. 擷取文獻內容。
3. 準備語意檢索（啟用時）。

擷取包括準備、上傳、服務端等待、解析、下載和本機儲存。服務供應商的頁數百分比僅表示解析進度，並非整個工作流程的完成比例。可以檢視錯誤並使用取消、重試操作；重試向量階段不會重新上傳 PDF。

## 4. 閱讀結果

在 Zotero 原生閱讀器中開啟 PDF，點選 **M** 顯示 Markdown 伴讀。如果處理完成前已開啟閱讀器，請關閉後重新開啟。透過目錄、文內搜尋和引文預覽導覽，詳見[閱讀與編輯](reader.md)。

## 5. 檢索或連線用戶端

已釋出正文可直接進行文字檢索，無需嵌入服務。語意檢索需要設定並啟用模型服務，等待索引完成。隨後可[檢索](search.md)或[連線本機 AI 用戶端](mcp.md)。
