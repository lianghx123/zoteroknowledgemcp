# 数据与隐私

本页说明当前预览版的数据行为。所选服务商和 AI 客户端有各自的条款、保留政策和费用。

## 本地保存内容

插件在 Zotero 数据目录的 `knowledgemcp/` 下保存知识数据库、处理状态、提取内容、产物和向量索引。SQLite 结构独立于 Zotero 原生数据库，原始附件仍由 Zotero 管理。

解析配置目前在本地 `parsing.json` 中明文保存可重复使用的 API 密钥，请保护数据目录和备份。嵌入与重排密钥使用 Gecko 登录管理器，设置仅保存凭据引用。MCP 令牌记录保存哈希，不保存可找回的密钥。

## 数据何时发送到外部

| 操作 | 发送给配置服务的数据 |
| --- | --- |
| PDF 解析 | 选定 PDF 的文件内容 |
| 内容嵌入 | 选定的提取文本片段 |
| 语义查询 | 待嵌入的查询文本 |
| 可选重排 | 查询及候选片段 |
| 授权 MCP 访问 | 将请求的知识内容返回客户端 |

本地文本检索和索引修复不需要嵌入请求。插件不提供自己的云同步或远程账号服务；外部客户端可能有额外的模型和网络行为。

## 备份与移除

外部备份完整数据目录（含 `knowledgemcp/`）前请关闭 Zotero。数据库升级快照不包含全部文献产物和索引，不能代替完整备份。

禁用或卸载插件会保留数据。Zotero 数据目录重置或账号切换可能删除目录，包括插件存储及本地快照；请将备份放在目录之外。插件暂不提供完整备份恢复或数据库结构降级工具。

## 分享问题信息

分享日志前，检查 PDF 正文、标题、本地路径、服务地址和凭据。不要向公开问题附加 Zotero 数据目录、知识数据库、令牌或服务密钥。参见[支持](support.md)。
