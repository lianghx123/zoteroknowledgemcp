# 知識庫

知識庫及其資料夾組織外掛中選定的文獻，獨立於 Zotero 個人庫、群組庫和原生分類。同一文獻可屬於多個知識位置，並共享已處理內容。

## 新增文獻

在 Zotero 原生條目或分類的右鍵選單中選擇**新增至知識庫**及目標位置。選擇子附件會新增其父文獻並關聯附件；獨立筆記和批註不會作為獨立文獻加入。

一次性新增分類只包括其直接條目；持續分類繫結另有後代同步工作流程。啟用解析後，符合條件的 PDF 可進入處理。缺失的 PDF 需先在 Zotero 下載或恢復，外掛不會自動下載。

## 同步分類

透過分類同步操作，將原生分類與知識位置明確繫結。繫結可映象後代；一次性新增並不建立持續繫結。在同步或任務檢視中檢視狀態與進度。

同步為單向：原生後設資料修改重新整理知識副本，整理知識資料夾不會重新命名或移動 Zotero 原生分類。

## 移除與恢復

從資料夾移除文獻只移除該放置關係；從知識庫移除則影響該庫中的成員關係，其他庫的成員關係可保留。這些操作不會刪除原始 Zotero 條目或 PDF。

在知識庫資源回收筒檢視和恢復可恢復的外掛移除項。永久刪除前請核對目標；資源回收筒不是外部備份。

Zotero 原生資源回收筒或不可用來源可能使文獻不再出現在活動知識結果中。恢復原條目並重新整理後設資料可恢復可用性。重設和備份行為見[資料與隱私](privacy.md)。
